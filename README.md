# MicroClear - AI-Based Microplastic Pollution Risk Assessment and Mitigation System

## 📌 Overview
MicroClear is an AI-powered system for detecting microplastic pollution and assessing water quality risk using Machine Learning.

## 🚀 Features
- ML-based risk prediction (Random Forest)
- Microplastic detection (YOLOv8)
- Streamlit interactive dashboard
- Hybrid ML + Rule-based safety system

## 🧠 Model
- Features: pH, TDS, Turbidity, Microplastics
- Output: Low / Medium / High Risk
- Accuracy: ~98%
